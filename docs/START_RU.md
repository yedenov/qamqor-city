# Как запустить и посмотреть Qamqor City

Это приложение о полезных городских инициативах: можно находить идеи, сохранять их, создавать свои, собирать план участия и отмечать выполненные задачи. Всё работает локально, без регистрации.

## Быстрый запуск на Windows

1. Убедитесь, что установлен Node.js версии 22 или новее: команда `node --version` покажет версию.
2. Откройте папку проекта и дважды нажмите `RUN.cmd`.
3. Откроется браузер по адресу `http://127.0.0.1:4174`. Если приложение ещё не загрузилось, обновите вкладку через секунду.
4. Не закрывайте окно терминала, пока пользуетесь приложением. Для остановки нажмите в нём Ctrl+C.

Пакеты устанавливать не нужно. Если открывать `index.html` двойным щелчком, браузер может блокировать JavaScript-модули, поэтому используйте запуск через сервер.

## Через PowerShell или терминал

Откройте терминал в папке проекта:

```powershell
npm start
```

Затем откройте `http://127.0.0.1:4174`.

Проверка кода:

```powershell
npm test
npm run check
```

Если порт занят, возможно, сервер уже работает. Сначала откройте указанный адрес. Для выбора другого порта в PowerShell:

```powershell
$env:PORT = '4176'
npm start
```

Другой порт означает отдельное пространство браузерного хранилища. Для переноса данных используйте экспорт и импорт.

## Что попробовать

1. **Инициативы** → выберите «Экология», найдите «Зелёные выходные».
2. Нажмите закладку и откройте карточку.
3. Нажмите **Добавить в мой план**; отметьте первую задачу.
4. В **Мои дела** добавьте личную заметку.
5. В **Мой вклад** посмотрите, как изменились диаграмма, процент и достижения.
6. В **Карта добрых дел** переключайте темы и нажимайте метки.
7. В **Календарь** выберите день с точкой; перейдите к событию.
8. Нажмите **Создать инициативу**, заполните форму и наблюдайте за предпросмотром.
9. В **Профиль** измените имя, сделайте экспорт, обновите страницу.

## Где сохраняются данные

Только в этом браузере, для этого адреса. Закладки, планы, созданные идеи и заметки остаются после обычного обновления страницы. Они не появляются автоматически на другом компьютере или в другом браузере. В режиме инкогнито сохранение может быть временным.

В **Профиль → Экспорт** можно скачать JSON-копию. **Импорт** проверяет файл и после подтверждения заменяет текущее пространство. **Сбросить** удаляет локальные данные после отдельного подтверждения.

## Как понимать демонстрацию

Двенадцать готовых инициатив — примеры, даты — учебный сценарий. Никто не получает заявку, когда вы добавляете дело в план. Карта схематическая. Выполненные задачи и достижения отражают ваши локальные отметки, а не доказанное участие в реальном мероприятии. Созданные идеи не публикуются для других пользователей.

## Если что-то не работает

- Пустая страница при открытии файла: запустите через `npm start`.
- Команда `node` не найдена: установите Node.js 22+ и заново откройте терминал.
- После обновления исчезли данные: проверьте тот же браузер, адрес и порт; браузер может запрещать постоянное хранилище.
- Не принимается JSON: используйте файл экспорта именно Qamqor City; максимальный размер 500 КБ.
- Интернет недоступен: приложение работает, но шрифт Manrope может замениться системным.
